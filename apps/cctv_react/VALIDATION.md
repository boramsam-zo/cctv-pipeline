# 프런트엔드 테스트 기록 — 2026-10-06

## 변경 이유와 범위

사용자 요청으로 Streamlit 원본을 보존하고 React 프런트엔드를 독립 제작했다. 후속 지시에 따라 실제 사건/API/영상 연결은 미뤘다. UI 데이터 6개는 명시적인 합성 테스트 사례이며 실제 모델 결과가 아니다. React 상태 변경으로 목록/상세를 전환하고 필터를 유지한다. 서버·DB·Streamlit 소스·배포·모델 변경은 없다.

## 실행 환경과 검사

- Node v24.21.0, npm 9.6.3
- React 19.2.0, TypeScript 5.9.3, Vite 7.1.9. 정확한 의존성은 package-lock.json 참조.
- `npm test`: 2개 통과. 검색+모델+상태 결합, 대소문자 검색, 빈 결과와 필터 축소 후 페이지 범위.
- `npm run build`: TypeScript strict 검사 및 Vite 프로덕션 빌드 성공. JS 209.83 kB / gzip 65.93 kB, CSS 12.55 kB / gzip 3.50 kB.
- 실제 브라우저: 없는 검색어→빈 상태→초기화, X3D-S→3건, 사건 상세 진입, 주석 이미지 탭, 보고서 6절 펼침/접기, 목록 복귀→모델 필터 유지, 2열→2페이지→2건, 후보 없음 필터→1건/1페이지 확인.
- 실제 브라우저 데스크톱 1600×900 목록·상세, 1920×1080 목록 가로 넘침 없음. 모바일 390×844 목록·상세에서도 가로 넘침 없음.

## 미검증

실제 영상 재생, 실제 저장 보고서의 동일성, 운영 API/인증/권한, EC2 부하, 실데이터 로딩 시간, 서버 배포는 미실행이다. 현재 프런트 단독 전환을 기존 운영 Streamlit의 전체 로딩과 정량 성능 비교로 주장하지 않는다. JSON 다운로드는 가상 데이터 전용이다.


## 후속 UI 수정 — 기존 관제 배치 + 빈 영역 목업

사용자 요청으로 별도 사이드바 디자인을 기존 Streamlit 관제 구조로 변경했다. Streamlit 원본은 수정하지 않았다. 16개 합성 작업으로3×3/4×4, 상단집계/차트/표, 상세260px 목록·영상/VLM·확인/기관 카드, 6절 보고, 문서 원문, 수동2초 알림을 구성했다. SVG 합성 장면 재생은 CSS 애니메이션이며 실제 동영상/모델 결과가 아니다.

브라우저1600×900에서3×3 9카드/4×4 16카드·260px 목록·6절 보고·목업 재생/정지·주석탭·목록 사건전환·보고판 전환 확인. 1920×1080 목록 가로넘침0 확인. 운영 데이터/영상/속도 비교는 미실행이다. 앞선6개 가상사례/2열3열/JSON다운로드는 첫 버전 이력이며 이번 구현은 README를 따른다.

최종 보정 후 빌드 통과. 후보 없음2개를 영상 후보 집계에서 제외(14개)하고 시간 표시를 후보 없음으로 구분했다. 실제 브라우저에서2초 알림 표시·읽음·동일 사건MOCK-001 열기·초기화 확인. 모바일390×844 상세의 가로 목록 min-content 확장 문제를 minmax(0,1fr)/min-width:0으로 수정하고 목록/상세 가로넘침0을 재확인했다.


## 집계 레이아웃 수정 2026-10-06

사용자 요청으로 작업 상태/접수 시간대 차트를 제거하고 영상별 설명·보고 준비 표와 사고 유형 분포를 같은 행의2열로 배치했다. 모바일760px 이하는 세로배치로 유지한다. 기존 Streamlit 변경 없음.
