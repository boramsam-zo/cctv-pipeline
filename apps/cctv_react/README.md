# React 관제 프런트엔드 목업

기존 Streamlit 파일과 운영 서버를 보존하고 control_room.py/CSS의 관제 UI 배치를 React로 재현합니다. 실제 API·영상·모델·DB는 연결하지 않습니다.

## 실행

```sh
npm ci
npm run dev
```

http://127.0.0.1:5174/ 에서 테스트합니다.

```sh
npm test
npm run build
```

## 화면

- 상단 관제 제목·조회 기록·집계 4개, 상태/시간대 차트, 설명·보고 준비 표, 유형 분포
- 16개 목업 작업으로 3×3·4×4 목록, 페이지/검색/모델·상태 필터
- 상세: 왼쪽260px 목록 / 중앙 영상·VLM / 오른쪽 확인 사항·기관 근거
- 원본/클립/박스 이미지 탭, SVG 합성 CCTV 장면과 재생·일시정지 애니메이션
- 6절 보고/관찰 상세/문서 원문 펼침, 보고 판 전환
- 수동2초 알림 재현/같은 사건 열기/읽음/초기화

모든 작업 ID·카메라·시각·보고·기관 문서는 명시적인 UI 목업입니다. 실제 영상 재생과 실제 사고 판단이 아니며, 목업 문서는 법령이나 공식 기관 지침이 아닙니다. 후보 없음은 정상 확정과 구분합니다.

## 후속 연결

실제 연결 시 응답 어댑터와 사건/보고 동일성 검증을 적용해야 합니다. 현재 브라우저는 API를 호출하지 않습니다. 운영 API/비밀값은 프런트에 넣지 말고 별도 서버 프록시에서 읽기 전용으로 연결합니다. 이번에는 기존 배포/모델/DB를 바꾸지 않았습니다.
