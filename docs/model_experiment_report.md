# R3D-18 기반 도로 CCTV 사고탐지

개발·실험 결과 보고서 · 2026-09-26

**목표:** 학습에 사용하지 않은 녹화 도로 CCTV에서 충돌·전복 의심 구간을 찾고, 원본 시각과 영상 근거를 제시한다. 사고 미탐 감소를 우선하면서 정상 통행의 오탐과 탐지 지연을 함께 평가한다.

> 현재 상태는 모델 개발·비교평가 단계다. 원본631은 비교 기준이며 운영 합격 모델이 아니다. 미래 영상에서 미탐 0을 보장하지 않는다. 이 보고서는 기존 결과를 정리한 것으로 새 학습·새 예측을 실행하지 않았다.


## 핵심 결과 요약

- **원본631 학습 완료:** 사고 403 + 정상 228구간으로 분류층만 5 epoch, 3,155회 업데이트했다. 특징 추출부와 BatchNorm 상태 보존, 저장·재개·재로딩 검사 기록을 확인했다. [S01–S04]
- **학습 경과 기록:** 온라인 평균 loss는 0.4675 → 0.2577로 감소했다. 원본631의 epoch별 검증 지표는 미측정이며, loss 감소를 일반화 성능 개선으로 해석하지 않는다. [S03]
- **개선 실험 비교:** 자료 보강, 균형추출, 분류층 추가학습, 마지막 합성곱 미세조정을 비교했다. 작은 고정 개발목록에서는 원본631을 교체할 조건을 충족하지 못했다. [S05–S07]
- **새 원본100 비교 완료:** 사고 80영상 + 정상 20연속 이미지 시퀀스를 두 모델로 처리했다. 주 지표는 미분류가 없는 동일 81원본에서 계산했다. [S08–S11]
- **개선과 손실을 함께 확인:** 마지막 실험모델의 정상창 오탐은 1,015 → 562로 줄었지만 사고 원본 미탐이 0 → 1로 늘었다. 두 모델을 별도 보존하고 교체하지 않았다. [S08, S13–S14]


## 구현 범위와 분석 흐름

```text
녹화 CCTV 영상 / 연속 JPG 시퀀스
  → 파일·시간정보·정답 근거·사용 이력 확인
  → 2초 구간에서 16프레임 선택 / 224×224 letterbox
  → RGB 정규화 → R3D-18 → 정상·사고 logits
  → 고정 판정 기준 → 원본 시간축에 예측 연결
  → 미탐·오탐·미분류 집계 → JSON·그래프·HTML 보고서
```

| 구성 | 현재 역할 | 상태 |
| --- | --- | --- |
| 자료·전처리 모듈 | 원본/구간 목록, 해시, 시각, 입력 배열·미리보기 | 구현·사용 |
| R3D-18 | 최근 구간의 정상/사고 이진 분류 | 학습·평가 실행 |
| 연속영상 분석 | 2초 입력을 1초 간격으로 이동하며 판정 시각 저장 | 녹화영상에서 실행 |
| 결과 전달 | Colab 출력, Drive 결과, JSON·HTML·그래프 | 사용 중 |
| 실시간 CCTV 서비스 | 상시 스트림·운영 경보·웹 통합 | 운영 성능 미검증·통합 서비스 미완료 |
| 차량 탐지·추적 | 차량 바운딩박스·ID·궤적 | 현재 R3D-18 실험 범위에 없음 |

R3D-18은 영상 구간의 공간·시간 특징을 처리하는 분류 모델이다. 현재 구현이 사고 차량의 위치를 직접 검출하거나 차량을 추적하는 것은 아니다. 실시간 서비스 목표와 현재 완료한 녹화영상 실험을 구분한다.


## 데이터 구성과 정답 근거

원본631의 숫자 631은 **학습에 사용한 구간 수**다. 631개의 독립 CCTV나 631 epoch를 뜻하지 않는다. 원본 파일 수·구간 수·독립 사건/카메라 수를 별도로 관리한다. [S01]

| 학습 구성 | 구간 수 | 정답 근거 |
| --- | --- | --- |
| ACCIDENT 사고 | 403 | metadata-real.csv 사고 시점에서 파생한 라벨 |
| DETRAC 정상 | 200 | 사용자 정상 가정 |
| ACCIDENT 정상 | 6 | 사용자가 정상으로 확인한 구간 |
| ACCIDENT 임시 정상 | 22 | 관찰 기반 임시 라벨; 공식 CSV 정상·사람 검수 확정과 구분 |
| 합계 | 631 | 사고 403 / 정상 228 |

631 학습에는 새100 비교자료를 넣지 않았다. 신규 비교자료는 사고 80 MP4 + DETRAC 정상 20시퀀스로, 100개 원본을 따로 확보했다. 같은 11개 영상을 잘라 100개로 표시한 것이 아니다. 다만 서로 다른 파일이 서로 다른 카메라·사건을 보장하지는 않는다. [S08, S15]

공식 test 일부는 사용자 승인으로 개발 비교에 배정했다. 사용분은 이후 학습이나 미노출 최종시험으로 재사용하지 않는다. 남은 사고 1,432파일/1,354파일명 묶음과 정상 20시퀀스는 최종시험 후보로 보호한다. 파일명 묶음이 독립 사건 수라는 뜻은 아니다. [S15]


## 데이터 점검과 전처리

- 원본 사용 이력, 알려진 학습·평가 중복, 파일 해시, 디코딩, 프레임 시각과 구간 경계를 점검했다.
- 학습631의 사고·정상 출처와 주야간 분포를 살펴보는 목적별 데이터 탐색·진단을 진행했다. 모든 현장 조건을 대표하는 포괄적 EDA가 완료됐다는 뜻은 아니다.
- 사고 시점 주석에서 파생한 구간 정답과 사람이 확인한 정답을 분리했다. 사고 이후·주석이 없는 모든 구간을 자동 정상으로 바꾸지 않았다.

| 항목 | 사용 규격 |
| --- | --- |
| 시간 입력 | 2초 구간 / 16프레임; 원본 시각에 가까운 프레임 선택 |
| 공간 입력 | 224×224 letterbox; 종횡비 유지와 패딩, 일괄 상단 잘라내기 없음 |
| 저장 배열 | [16, 224, 224, 3], RGB uint8 |
| 모델 입력 | [3, 16, 224, 224], float32; batch 축 별도 |

| 클래스·판정 | normal=0 / accident=1; 큰 logit 선택, 동률이면 정상 |

> 저FPS 처리 정책은 실험별 기록을 따른다. 과거 일부 준비자료에는 반복프레임을 허용했지만, 이번 새100 연속평가는 16개의 서로 다른 프레임과 최대 시각 오차 0.125초를 요구했다. 조건에 못 미치는 창은 미분류로 남겼다. 과거 참고30과 입력정책·채점단위가 동일하다고 주장하지 않는다. [S04, S08, S11–S12]

사고 점수는 두 클래스 점수에서 계산한 값이며 검증된 실제 사고 발생 확률이 아니다. 처리불가와 정상 판정도 별개다.

## 오탐 진단과 제한적 특징층 실험

원본631으로 학습 정상228구간을 다시 판정했을 때 46구간이 오탐이었다. 그중 사람이 정상으로 재확인한6구간도 모두 오탐이었다. 학습자료에 대한 적합도 진단이며 독립 개발성능에 합산하지 않는다. [S05, S12]

Grad-CAM으로 정상6구간의 사고 클래스에 기여하는 영역을 확인했다. 일부 지도에서 나무·하늘·원경 등 배경이 강조됐다. 이는 사고 차량의 바운딩박스도, 실제 사고 확률 지도도 아니며 배경이 오탐의 원인이라는 인과 증명은 아니다.

이후 실제 학습 코드와 진단 코드를 대조해 모델·코드 해시, 입력·정규화·프레임 순서, 라벨/클래스, 학습 순서, 저장·로딩, 고정 층을 확인했다. 확보된 근거 범위에서 연결 불일치는 발견하지 못했다. 정상28 입력은 로컬 재해시했고, DETRAC200 배열·일부 과거 실행환경 등 미확인 범위는 별도로 남겼다. [S12]
