## 무엇을 기록했고 무엇을 확정하지 않았나

사용자의 명시적인 정상 판정을 해당 구간의 `label_review.status=approved`, `label=normal`, 클래스 순서 `[normal,accident]`의 `target=0`으로 연결했다. 이는 사람의 구간 판정을 기록한 것이며 모델 예측이나 공식 원본 정답이 아니다. 정상은 이 프로젝트의 사고 장면 포함 여부 기준이며 안전 운전·신호 준수 여부 자체를 맞히는 모델이 아니다.

근거에 없는 “충돌·전복이 전혀 없음을 확인함”을 사용자 발언처럼 덧붙이지 않았다. 앞으로는 실제로 그렇게 확인한 경우에만 “해당 구간에서 차량 간 접촉·충돌·전복이 보이지 않음”처럼 쓰면 사고 여부 기준이 더 명확해진다. 이전 관찰을 지우거나 바꾸도록 요구하는 것이 아니다.

비어 있던 잘림·순서·앞뒤 장면 추가 확인 항목은 `human_submission`에서 빈 문자열 그대로 보존하고 `preview_review.missing_or_order_problem=null`, `status=quality_question_unanswered`로 기록했다. `null`은 문제 없음이 아니라 아직 답하지 않음이다. 정상 판정·재생 가능 응답과 이 항목의 완료 여부는 별개다.

추가로 답할 내용 하나: **세 구간 모두 잘림·순서 문제가 없고 앞뒤 장면을 더 볼 필요가 없었는지** 확인한다. 실제로 그렇다면 “세 구간 모두 잘림·순서 문제 없음, 추가 확인 필요 없음”이라고 답할 수 있다. 다른 점이 있으면 해당 ID와 내용을 적는다.

## 원본·미리보기·학습 상태

- 원본 `qmul_junction.avi`의 해시와 각 MP4 해시, 원본 구간·동일 파일 그룹·검수자/날짜를 기존 manifest에 연결했다. 사용자 입력의 `정상 /`는 의미 있는 판정 `정상`으로 정리하고 원문도 남겼다.
- 검수 전 `artifacts/data-check/qmul-review-01/manifest.json`의 `target=null`, `user_player_verified=false`는 **그 실행 당시 결과**로 보존했다. 최신 사용자 재생 확인은 새 검수 JSON의 `preview_review.playable=true`에 있다.
- `training_authorized=false`, `model_input_approved=false`를 유지한다. 이번 6초 검수는 224픽셀·16프레임 모델 입력이나 학습 사용을 승인한 것이 아니다. 이 JSON은 기존 ACCIDENT 학습 설정에 연결하지 않았다.
- 세 구간은 동일 로컬 파일 그룹 하나다. 공식 분할·상위 원본/사건 관계·공식 설명과 로컬 파일 시간 정보 차이는 여전히 미확인이다. 원본 전체를 정상으로 만들거나 구간들을 서로 다른 학습/평가 세트로 나누지 않는다.
- 현재 사람 판정 기록은 기존 ACCIDENT 사고 3구간과 이번 QMUL 정상 3구간이다. 기존 사고 자료는 공식 test이며 실제 학습용 사고 자료 확보·독립 정상 자료·분할 준비 완료가 아니다.

실행 명령: `.venv-model-check/bin/python artifacts/label-review/qmul-dahye-20260920-01/validate_review.py`. **18항목 통과, `[0,0,0]`, 품질 항목 미응답 3, 0.037초**다. 결과는 [validation.json](../../artifacts/label-review/qmul-dahye-20260920-01/validation.json), 실행 코드는 해당 폴더에 있다. 프로그램 코드 변경이 없는 기록 작업이므로 단위 테스트·디코딩·전처리·학습을 재실행하지 않았다. 직전 13개 테스트 통과를 이번 새 테스트 결과로 세지 않는다.
