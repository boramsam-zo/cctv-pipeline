## 실제 실행과 한계

기존 코드만 재사용했다. `run()` → `process_sample()` → `approved_target()`(null 유지) → `sample_frames()` → `save_frames()` 순서다. 사람이 더 잘 보기 위한 512픽셀 미리보기이며 승인된 모델 입력 224픽셀·정규화·학습 설정을 바꾸지 않았다. 향후 학습 후보의 224픽셀 식별성은 별도로 확인해야 한다.

```bash
.venv-model-check/bin/python scripts/preprocess_samples.py \
  --data-root data/local/accident \
  --plan artifacts/label-review/codex-draft-20260920-01/plan.json \
  --output artifacts/label-review/codex-draft-20260920-01/prepared
```

위 명령을 외부 60초 상한으로 실행했다. 기존 코드는 영상당 45초·디코딩 900프레임/2,000패킷/35초 상한을 적용한다. 재실행 시 `--output`은 **아직 없는 새 폴더**로 지정해야 한다. 기존 결과를 덮어쓰는 명령이 아니다.

- 실제 경과시간: **3.006초**. 3개 미확정, 오류 0, 승인 입력 0. 학습·추론 모델 없음.

## 추가 영상의 수와 종류 — 제안이며 확보·실행 완료 아님

**작은 실제 자료 예비 실험의 준비 목표로 새 사고 10개 + 정상 10개, 총 20개의 서로 독립된 원본/사건 후보를 제안한다.** 이는 논문이나 원본 데이터셋이 정한 최소 수량도, 성능을 보장하는 수량도 아니다. 검수·분할·학습 저장 흐름의 문제를 작은 규모에서 찾기 위한 작업상 제안이다. 부담되면 각 3개씩 먼저 제공하고, 적합성을 확인한 뒤 나머지를 준비한다. 20개는 그 첫 6개를 포함한 목표다.

- 사고 후보는 실제 충돌 또는 전복 발생 장면이 보이는 CCTV 영상으로 준비한다. ACCIDENT에서 고를 때 공식 학습용 행인지 CSV로 먼저 확인한다. IID/지리 분할 선택은 아직 미정이므로 둘 다 train인 후보부터 살펴볼 수 있고, 서로 다르면 보류해 설명한다. 파일명이나 사고 장면 유무만으로 train을 정하지 않는다.
- 정상 후보는 사고가 없는 실제 도로 장면이다. 정상 주행·정체·신호 대기 등의 검수 가능한 구간을 포함하되, 주석이 없거나 사고 이전이라는 이유로 정상 확정하지 않는다. 사고 영상과 촬영 방식·주야간·해상도가 비슷한 후보도 필요하다.
- 가능한 한 고정 CCTV 시점을 사용한다. 블랙박스·뉴스 편집본·시뮬레이터는 촬영/생성 조건이 달라 현재 후보와 자동으로 섞지 않는다. `real/synthetic`은 생성 출처, `normal/accident`는 내용 판정이다. 합성 영상을 지금 추가할 필요는 없다.
- 같은 사건의 재편집 영상 10개는 독립된 사건 10개가 아니다. 사건/원본 관계를 모르면 미확인으로 남긴다. 확보 뒤 그룹 단위로 train/validation을 분리하고 양쪽에 두 클래스가 있는지 확인한다. 현재 공식 test 여섯 개는 이 학습 후보 수에 포함하지 않는다.
- 수량만 채워져도 바로 학습하지 않는다. 승인 구간 정답·그룹/분할·전처리 확인·공식 가중치 준비와 실행 승인이 남아 있다. 기존 한 번에 3샘플 제한을 이번에 늘리지 않았다. 외부 정상 영상은 원본 ACCIDENT CSV에 행을 덧붙이지 않고 별도 목록으로 받은 뒤 연결 방법을 정한다.
- 일반화 성능에 필요한 수량은 아직 정할 수 없다. 이후 자료 수를 늘릴 때 고정된 검증 기준의 학습/검증 성능 변화, 사고 유형·촬영 조건별 오류, 정상 영상의 총 관측 시간 등을 함께 봐야 한다. 학습 곡선은 자료 수에 따른 학습·검증 점수 변화를 보는 방법이다([scikit-learn 공식 설명](https://scikit-learn.org/stable/modules/learning_curve.html#learning-curve)). 이 문서는 위의 20개라는 수량을 보증하는 출처가 아니다.

다음 작업 하나: 사용자가 이 초안을 검토한 응답을 반영한다. 학습용 후보 자료 점검과 실제 학습은 별도 후속 범위로 남긴다.
